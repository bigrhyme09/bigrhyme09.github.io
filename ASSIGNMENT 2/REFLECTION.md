# 1. Explain the difference between flex-direction: row and flex-direction: column.

Flex Direction: `row` vs. `column`
`flex-direction: row` arranges flex items horizontally along the inline main axis left to right by default. For `flex-direction: column` it rotates the main axis by 90 degrees, stacking the items vertically along the block axis (top to bottom). In desktop navigation bars, `row` is standard for displaying items side by side whereas `column` is used on mobile screens so items stack into a clean and touch-friendly vertical menu.

## 2. Why is it important to use relative units (like %, vh, or rem) instead of fixed pixels (px) for responsive design?

To use relative units, fixed pixels (`px`) are absolute units that do not scale when a user's viewport changes or when a user adjusts their default browser font settings for accessibility. This often leads to overflow or layout breaks on mobile screens. Relative units like `%`, `rem`, `vh`, and `vw` scale fluidly relative to parent containers or the root font size. It enables layouts to adapt smoothly across diverse devices and screen resolutions.
